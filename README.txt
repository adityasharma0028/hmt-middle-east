HMT website product image assets

These product images were extracted from the Bosch Global Tools Catalog 2026 UAE PDF you supplied. They are illustrative catalogue images; do not assume a specific model number or current HMT stock availability unless verified against the matching catalogue entry and HMT inventory.

INSTALL
1. Extract the public folder into your React/Vite project root (merge it with your existing public folder).
2. The images will be available at URLs such as /products/impact-drill-01.jpg
3. In React, use <img src="/products/impact-drill-01.jpg" alt="Bosch impact drill" />.
